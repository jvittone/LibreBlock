# Politique de confidentialité de LibreBlock

*Dernière mise à jour : 3 novembre 2026*

LibreBlock est une application Android gratuite et open source qui bloque les applications choisies par l'utilisateur.

## Données collectées
**Aucune.** LibreBlock ne collecte, ne stocke sur un serveur, ne partage et ne vend aucune donnée personnelle.
L'application ne demande pas l'autorisation d'accès à Internet : elle ne peut rien envoyer hors du téléphone.

## Données stockées sur l'appareil
Les réglages (liste des applications bloquées, horaires, sessions) sont enregistrés uniquement dans le stockage
privé de l'application, sur le téléphone. Ils sont supprimés lors de la désinstallation et exclus des sauvegardes
automatiques.

## Service d'accessibilité
LibreBlock utilise l'API AccessibilityService d'Android, avec le consentement explicite de l'utilisateur, pour :
- détecter quelle application est affichée au premier plan, afin d'afficher l'écran de blocage si elle fait partie
  des applications bloquées ;
- en mode strict uniquement, lire le texte des écrans Paramètres et de désinstallation afin de refermer ceux qui
  permettraient de désactiver ou de désinstaller LibreBlock.

Ces informations sont traitées instantanément sur l'appareil. Elles ne sont ni enregistrées ni transmises.

## Notifications
LibreBlock affiche des notifications locales au début et à la fin des pauses des sessions de travail.

## Liste des applications installées
LibreBlock lit la liste des applications lançables du téléphone pour permettre à l'utilisateur de choisir celles à
bloquer. Cette liste n'est ni enregistrée en dehors des choix de l'utilisateur ni transmise.

## Contact
Pour toute question : libreblock.app@gmail.com

# LibreBlock Privacy Policy

*Last updated: November 3, 2026*

LibreBlock is a free, open-source Android app that blocks the apps the user chooses.

- **No data is collected, shared or sold.** The app does not request Internet access.
- Settings (blocked apps, schedules, sessions) are stored only in the app's private storage on the device and are
  excluded from backups.
- With the user's explicit consent, LibreBlock uses the AccessibilityService API to detect which app is in the
  foreground and show the block screen, and, in strict mode only, to read the text of Settings and uninstall screens
  in order to close those that would disable or uninstall LibreBlock. This is processed on the device in real time
  and never stored or transmitted.
- Local notifications announce the start and end of breaks.
- The list of launchable apps is read only so the user can choose which ones to block.

Contact: libreblock.app@gmail.com
